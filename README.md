# Applisound - Web Application 

#### Auteur du projet : Amilcar Joao (Développeur Front-End Angular & Back-End Java SpringBoot Junior)

#### Projet personnel lié au domaine de la musique et des services audio professionnels.


## Description du projet

Applisound est une plateforme de services audio professionnels. Le projet offre plusieurs services audio:

1. **Soundtracks** - Bandes sonores personnalisées
2. **Jingles** - Identités sonores pour marques
3. **Voiceovers** - Services de voix off professionnelles
4. **Sound Design** - Conception sonore pour interfaces, jeux, films
5. **Hymnes** - Compositions musicales spécifiques
6. **Cession de droits musicaux** 

L'application est développée avec Angular et propose une interface multilingue (15+ langues supportées) avec un design moderne et responsive. Elle intègre également des fonctionnalités avancées comme:

- Lecteurs audio personnalisés
- Formulaires multi-étapes pour les commandes
- Système de devis avec signature électronique
- Intégration blockchain pour la gestion des contrats
- Système d'authentification utilisateur

# Applisound - Web Application 

#### Project Author: Amilcar Joao (Junior Angular Front-End & Java SpringBoot Back-End Developer)

#### Personal project related to music and professional audio services.


## Project Description

Applisound is a professional audio services platform. The project offers several audio services:

1. **Soundtracks** - Custom soundtracks
2. **Jingles** - Sound identities for brands
3. **Voiceovers** - Professional voiceover services
4. **Sound Design** - Sound design for interfaces, games, films
5. **Hymns** - Specific musical compositions
6. **Music Rights Transfer** 

The application is developed with Angular and offers a multilingual interface (15+ supported languages) with a modern and responsive design. It also integrates advanced features such as:

- Custom audio players
- Multi-step order forms
- Quote system with electronic signature
- Blockchain integration for contract management
- User authentication system
